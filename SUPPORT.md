# Support

- **A bug in `standards-sync`, or a rule that is wrong or contradicts
  another**: open an [issue](https://github.com/sebastienrousseau/standards/issues/new/choose).
- **A security problem**: report it privately, as [SECURITY.md](SECURITY.md)
  describes, never in an issue.
- **How to use it**: the [manual](https://sebastienrousseau.com/standards/)
  and `man standards-sync`.

This is maintained by one person, as time allows. There is no paid support.
